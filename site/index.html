Your agent fleet, in your pocket.

CC Dispatch attaches to the Claude Code, Codex and Grok sessions already running in your iTerm2 — reads them, answers their permission prompts, and pushes you the moment one needs you. Nothing gets restarted.

Why

You're not at your desk. The fleet is still running.

Permission prompts don't wait

An agent stalls on an approval and the whole session sits idle until you're back at the keyboard.

Status is invisible from afar

Is it working, stuck, or done? Without eyes on the pane there's no way to tell.

Restarting loses context

Most remote-access tools mean spinning up a fresh session. CC Dispatch just looks at the one that's already running.

Features

Everything the fleet needs, nothing it doesn't

>_

Attach, not restart

Reads existing iTerm2 panes via the Python API. Kill the server and your fleet is exactly as it was.

✓

Permission prompts from your pocket

See what an agent wants to do and approve or deny it from your phone.

🔔

Push when it needs you

Web-push notifications the moment a session finishes or stalls on input.

🔑

Passkey-only

WebAuthn login. A single-use bootstrap token in the startup QR registers your first passkey — then it's passkeys only.

🔒

Loopback + Tailscale

The server binds 127.0.0.1 only. tailscale serve terminates TLS — no listener for a stranger to find.

⚿

Credential broker

An agent requests a secret, you approve on your phone, it's released just-in-time from an encrypted vault.

🎤

Voice input

Local whisper.cpp transcription — nothing leaves the machine.

⌘

Multi-agent

Claude Code, Codex and Grok panes, side by side, each with its own critter on the yard.

Install

Install in 5 minutes

Runs on the Mac that's already running your iTerm2 fleet. macOS, iTerm2 with the Python API enabled, and Tailscale.

Clone the repo

git clone https://github.com/charlie-818/claude-dispatch.git
cd claude-dispatch

Set up the virtualenv

python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

Wire up the fleet-status hooks

So every Claude Code pane shows up in the fleet view.

cp examples/statusline.sh examples/cc-state.sh ~/.claude/
chmod +x ~/.claude/statusline.sh ~/.claude/cc-state.sh

Expose the port over your Tailnet

tailscale serve --bg 8788

Start the server

Run it from inside iTerm2, so it inherits ITERM2_COOKIE.

.venv/bin/python server.py

Scan the QR code

The server prints a QR with the bootstrap token baked in. Scan it, register a passkey, add the PWA to your home screen. Every visit after that is passkey-only.

Security posture

Binds loopback (127.0.0.1) only — reachability is Tailscale's job.

Passkey registration requires the one-time bootstrap token and a real TLS origin.

Writes are gated — keystrokes only reach panes confirmed to be running a known agent.

Integration secrets live in an encrypted vault, key held in the macOS keychain.
